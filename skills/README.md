## Как пользоваться каталогом

1. Выберите раздел и откройте навык по русскому названию.
2. Прочитайте `SKILL.md`: назначение, исходные данные, порядок работы и ожидаемый результат.
3. При необходимости откройте указанные в нём материалы `references/`.
4. Для работы с другим рынком явно задайте страну, язык, валюту и доступные источники данных.

Описание показывает назначение навыка, а не подтверждает наличие подключённых рекламных кабинетов, CRM или источников рыночных данных.
